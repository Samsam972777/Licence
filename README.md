# Licence

Calculs des moyennes des UE du BUT 1 R&T (R1.07 - Fondamentaux de la programmation).

## Fichiers

- Calcul_UE.ipynb : calcul des moyennes des 3 UE
  - Version 1 : notes et coefficients saisis au clavier
  - Version 2 : notes et coefficients dans des listes
  - Version 3 : notes et coefficients dans des dictionnaires
- Tkinter.ipynb : interface graphique avec Tkinter (saisie des notes et calcul des moyennes)
- Graphique_UE.ipynb : moyennes des 3 UE affichées dans un graphique en barres (vert / orange / rouge)
  - Version 1 : notes dans une liste
  - Version 2 : saisie des notes avec Tkinter

Pour Thonny : installer matplotlib avec `pip install matplotlib` (Outils → Ouvrir la console système).
